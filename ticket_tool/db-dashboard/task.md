# 概要
duck-dbのファイルをフロントエンド側でダッシュボードにするアプリを作成する。

# アーキテクチャ
- フロントエンド: React
- バックエンド: rust + duck-db + axtix-web
- データベース: duck-db
# フロントエンドとバックエンド
## バックエンド
- バックエンドは、duckdbのスキーマ情報を取得するAPIを提供する。
- バックエンドは、duckdbのデータを取得するAPIを提供する。データはparquet形式で提供する。
- バックエンドは、フロントエンドからSQLを受け取り、duckdbのデータを取得するAPIを提供する。
## フロントエンド
- フロントエンドは、バックエンドからスキーマ情報を取得して、ダッシュボードの作成用のUIを提供する。
- フロントエンドは、バックエンドからデータを取得して、OPFSに一度保存する。
- フロントエンドは、OPFSに保存したデータを表示する。
- フロントエンドは、ユーザーの操作によって動的にSQLを生成して、表示データを加工することができる。
- フロントエンドはダッシュボードの作成機能を提供し、その設定をバックエンドが保存する。
